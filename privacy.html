プライバシーポリシー（teilab-uploader）

最終更新: 2026年11月1日

1. このツールについて

teilab-uploader は、YouTube チャンネル「艇らぼ」の運営者が、自分のチャンネルのためだけに使う投稿ツールです。運営者以外の利用者はいません。

2. 使う Google のデータ

運営者自身の Google アカウントで許可した範囲で、YouTube API を通じて次のことだけを行います。

  • 動画のアップロードと公開日時の予約（youtube.upload）
  • 自分のチャンネルと動画の情報（公開状態など）の読み取り（youtube.readonly）
  • 自分のチャンネルの視聴統計の読み取り（yt-analytics.readonly）

3. データの保存と共有

  • 認証情報と取得したデータは、運営者の手元のパソコンにだけ保存します。
  • 第三者への提供、販売、広告への利用は一切しません。
  • 取得したデータは、チャンネル運営（投稿の確認と視聴の傾向の分析）にだけ使います。

4. 許可の取り消し

このツールへの許可は、Google アカウントの「サードパーティのアプリとサービス」（https://myaccount.google.com/connections）からいつでも取り消せます。

5. YouTube の規約

このツールは YouTube API サービスを利用しています。YouTube 利用規約（https://www.youtube.com/t/terms）と Google プライバシーポリシー（https://policies.google.com/privacy）が適用されます。

6. お問い合わせ

このポリシーについてのお問い合わせは、YouTube チャンネル「艇らぼ」までお寄せください。

Privacy Policy (English summary)

teilab-uploader is a private tool used only by the owner of the YouTube channel "艇らぼ". Using YouTube API Services with the owner's own Google account, it uploads and schedules videos (youtube.upload), reads the owner's channel and video information (youtube.readonly), and reads the owner's channel analytics (yt-analytics.readonly). Credentials and retrieved data are stored only on the owner's computer and are never shared with, sold to, or used for advertising by any third party. Access can be revoked at any time at https://myaccount.google.com/connections. This tool uses YouTube API Services; the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy) apply.
